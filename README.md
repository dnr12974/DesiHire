# DesiHire

## About the Project
DesiHire is a digital freelancing hub aimed at empowering marginalized communities by connecting talented professionals with clients in need of creative and technical services. It emphasizes local culture, craftsmanship, and sustainable work practices, creating an inclusive platform for both buyers and sellers.

## Functionalities
- **User Authentication & Authorization:** Secure registration and login using JWT-based authentication.
- **Gig Management:** Freelancers can create, update, and delete gigs with image and file uploads.
- **Messaging System:** Real-time messaging between clients and freelancers to ensure smooth communication.
- **Review System:** Clients can leave detailed reviews and ratings for services.
- **Multilingual Support:** Integrated Indian regional language selector that enables real-time translation and localized content, ensuring an accessible experience for users from diverse linguistic backgrounds.


## Basics & How to Start
1. **Clone the Repository:**
   ```sh
   git clone <repository_url>
   cd DesiHire
   ```
2. **Setup the Frontend:**
   ```sh
   npm install
   npm run dev
   ```
    This starts the Vite development server for the React frontend.
3. **Setup the Backend:**
   ```sh
   cd api
   npm install
   node server.js
   ```

## Tech Stack

- **Frontend:**
  - **React:** A component-based library for building interactive interfaces.
  - **Vite:** A fast development server and modern build tool optimized for performance.
  - **SCSS:** A CSS preprocessor that enables modular and maintainable styles.

- **Backend:**
  - **Node.js:** A JavaScript runtime for executing server-side code.
  - **Express:** A minimal and flexible Node.js web framework for building RESTful APIs.
  - **MongoDB with Mongoose:** A NoSQL database paired with Mongoose for object data modeling.

- **Utilities & Libraries:**
  - **JWT:** JSON Web Token for secure user authentication.
  - **Axios:** A promise-based HTTP client for making API requests.
  - **React Query:** A tool for managing and caching asynchronous state.
